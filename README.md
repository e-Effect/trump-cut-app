# trump-cut-app

## フレーズ保存の回帰テスト

Node.js 20.19以降の20系、22.13以降の22系、または24以降で実行できます。

```sh
npm ci
npm test
```

`tests/phrase-storage.test.cjs` は、`index.html` 全体を jsdom で読み込み、
実際の入力・変更・クリック・ファイル読み込みのイベント処理を検証します。
アプリの関数をテスト用に書き換えたり、保存処理を別実装へ置き換えたりしません。

- 52項目の本文・向き・自動リンクの保持、旧形式との互換性、自動保存、再読み込み
- 共有する模擬localStorageと遅延したstorageイベントによる、古いタブからの項目単位の編集反映
- 保存容量不足・アクセス拒否・破損データ、未保存の編集のメモリ保持とJSON出力、保存の再試行
- JSONの検証、確認ダイアログとファイル選択のキャンセル、バックアップ作成、全消去、復元
- バックアップ書き込みと本体書き込みそれぞれの失敗、復元時の保存失敗

テストはメモリ上の保存領域だけを使用し、外部通信を行いません。
実ブラウザの容量上限、同時書き込みの競合、端末固有の動作、クラウド通信は対象外です。
